# Сайт-портфолио — Александра Николаева

Статический сайт: чистый HTML/CSS/JS, без сборки и без зависимостей.
Открывается двойным кликом по `index.html`, публикуется перетаскиванием папки
`site` на любой хостинг.

---

## Что нужно сделать перед публикацией

### 1. Подключить форму обратной связи (5 минут)

Пока не подключена, форма открывает почтовую программу с готовым письмом —
работает, но заявка уйдёт только если у человека настроена почта на устройстве.

1. Зайти на **web3forms.com**, указать почту `alexneeaals@gmail.com` — сервис
   пришлёт **Access Key**.
2. Открыть `assets/js/main.js`, в самом верху найти строку:

   ```js
   var WEB3FORMS_KEY = '';
   ```

   и вставить ключ между кавычками.

После этого заявки будут приходить на почту сразу, без почтового клиента.

### 2. Ссылки на соцсети

В `index.html` в самом низу, в блоке `<footer>`, заменить `href="#"` на реальные
адреса Instagram, Behance и LinkedIn.

### 3. Проверить уровни владения инструментами

В слайдере «Карта компетенций» уровни проставлены по резюме. Поправить можно в
`assets/js/content.js` — секция `map.tools`, поле `v` (значения 1–4:
базовый, уверенный, продвинутый, экспертный). Менять нужно **в обоих языках**.

## Как править тексты

**Весь текст сайта лежит в одном файле — `assets/js/content.js`.**
В HTML текста нет, поэтому править разметку не нужно.

Файл состоит из двух частей:

- `window.CONTENT` — тексты интерфейса и секций, отдельно `ru` и `en`.
  Правку нужно вносить в обе версии, иначе при переключении языка
  останется старая формулировка.
- `window.PROJECTS` — 11 кейсов. У каждого свой блок `ru` и `en`:
  заголовок, локация, теги, описание, задача, вызов, решение, результат,
  цифры и подписи к изображениям.

### Добавить новый проект

1. Положить изображения в `assets/img/projects/<слаг>/`
   (первое — `hero.jpg`, дальше `01-…jpg`, `02-…jpg`).
2. Добавить блок в `window.PROJECTS` в `content.js` — проще всего скопировать
   соседний проект и заменить содержимое. Порядок в массиве = порядок в
   портфолио и переходы «предыдущий / следующий».
3. Скопировать любой файл из `projects/`, переименовать в `<слаг>.html` и
   заменить внутри: `<title>`, два `og:`-тега, путь к `og:image` и строку
   `window.PROJECT_SLUG = '<слаг>'`.

Количество подписей (`captions`) должно совпадать с количеством изображений.

Если для плитки в портфолио нужна не та картинка, что стоит обложкой кейса,
добавьте проекту поле `cover: '01-map.jpg'` — так сделано у «Странников долины».

### Картинки внутри блоков

Декоративные кадры лежат в `assets/img/decor/` и вставлены прямо в `index.html`
рядом с заголовками секций:

```html
<figure class="deco deco--tr" style="--rot:1.5deg;--w:20%">
```

`--rot` — наклон, `--w` — ширина в процентах от колонки, класс задаёт угол:
`deco--tr` (справа сверху), `deco--mr` (справа посередине), `deco--bl`
(слева снизу). Чтобы заменить кадр — положите файл в `decor/` и поправьте `src`.

### Раскладка блока «Сферы»

Плашки разбросаны не потоком, а по координатам — они заданы в
`assets/js/main.js`, массив `SECTOR_LAYOUT` (порядок совпадает с
`sectors.items` в `content.js`). У каждой: `x`/`y` в процентах, `rot` — наклон,
`style` — `box` (в бордовой рамке) или `line` (с подчёркиванием).
Кадры между плашками — массив `SECTOR_SHOTS` там же.

## Как опубликовать

**Netlify или Vercel** — открыть `app.netlify.com/drop` и перетащить туда папку
`site`. Сайт поднимется за минуту, дальше можно привязать свой домен.

**Обычный хостинг** — залить содержимое папки `site` в корень по FTP.

**GitHub Pages** — залить папку в репозиторий и включить Pages в настройках.

Никакой сборки, Node.js и команд не требуется — на сервер едут файлы как есть.

## Структура

```
site/
├── index.html              главная
├── projects/               11 страниц кейсов (тонкие оболочки)
├── assets/
│   ├── css/style.css       вся вёрстка и дизайн-система
│   ├── js/
│   │   ├── content.js      ← ВСЕ ТЕКСТЫ, RU + EN
│   │   ├── i18n.js         переключатель языка
│   │   ├── motion.js       анимация, курсор, параллакс
│   │   ├── main.js         главная + форма (здесь ключ Web3Forms)
│   │   └── project.js      рендер страницы кейса
│   └── img/                портрет, коллаж, изображения проектов
└── tools/                  скрипты извлечения картинок из PDF (в проде не нужны)
```

### Про папку `tools`

Одноразовые скрипты, которыми изображения доставались из исходных PDF.
На сайте не используются — можно не заливать на хостинг. Если понадобится
пересобрать картинки из PDF заново:

```bash
swift tools/extract-images.swift && bash tools/build-assets.sh
```

## Технические детали

- **Языки.** Выбор сохраняется в браузере, при следующем визите открывается
  тот же язык. По умолчанию русский, у иностранных посетителей — английский.
- **Анимация.** Коллаж на первом экране следует за курсором, кольцо курсора
  реагирует на ссылки, блоки появляются при прокрутке. Если в системе включено
  «уменьшить движение» — вся анимация отключается. На телефонах курсор и
  параллакс не запускаются.
- **Адаптив.** Проверено на 1440, 1024, 768 и 375 px.
- **Шрифты.** Playfair Display, Manrope, Cormorant Garamond — подключены с
  Google Fonts, все с кириллицей.
- **Вес.** Около 21 МБ, почти всё — изображения проектов (ужаты до 1800 px
  по длинной стороне). Картинки в галереях грузятся по мере прокрутки.
